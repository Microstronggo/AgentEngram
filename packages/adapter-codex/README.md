# @agentengram/adapter-codex

Codex Hook and MCP integration for portable transcript capture, recall, and typed long-term-memory formation.

Codex exposes an enhance-mode integration: AgentEngram does not replace Codex history or compaction.

```bash
pnpm dlx @agentengram/engine setup codex
pnpm dlx @agentengram/engine doctor --adapter codex
```

Documentation: <https://github.com/Microstronggo/AgentEngram#readme>
