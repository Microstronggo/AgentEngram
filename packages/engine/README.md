# @agentengram/engine

Framework-neutral Context and Memory Runtime for AI agents.

```bash
pnpm add @agentengram/engine
```

Use `@agentengram/engine/public` for application integration, `@agentengram/engine/adapter` for host adapters, and `@agentengram/engine/testing` for adapter conformance tests.

Documentation: <https://github.com/Microstronggo/AgentEngram>
