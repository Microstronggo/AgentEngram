# @agentengram/mcp

MCP stdio server for explicit AgentEngram remember, search, read, update, correction, feedback, and context-inspection operations.

```bash
pnpm add -g @agentengram/mcp
agentengram-mcp
```

MCP alone cannot replace a host Agent's context or compaction pipeline. Use a native adapter for managed-context behavior.

Documentation: <https://github.com/Microstronggo/AgentEngram>
