# @agentengram/adapter-pi

Pi extension for AgentEngram transcript mirroring, recall, long-term-memory formation, and explicit managed-context ownership.

```bash
pi install npm:@agentengram/adapter-pi
pnpm dlx @agentengram/engine setup pi
pnpm dlx @agentengram/engine doctor --adapter pi
```

Pi remains the owner of its operational transcript. AgentEngram stores a portable transcript and only replaces the model-facing context when `managed-context` is explicitly enabled.

Documentation: <https://github.com/Microstronggo/AgentEngram#readme>
